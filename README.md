# Zomato Delivery Analytics

## Project Overview
This project analyzes Zomato delivery operations using Python and Power BI.

The project focuses on:
- Data Cleaning & Preparation
- Exploratory Data Analysis (EDA)
- Traffic & Weather Impact Analysis
- Driver & Vehicle Performance
- Geographic Analysis
- Delivery Efficiency Analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Dashboard KPIs
- Total Orders
- Average Delivery Time
- Average Delivery Rating
- Average Delivery Distance
- Area Type Distribution

## Key Insights
- Traffic density has a stronger impact on delivery time than delivery distance.
- Poor weather combined with dense traffic leads to the longest delivery times.
- Better vehicle condition improves delivery performance.
- Metropolitan areas generate the highest order volume.
- Driver ratings decrease slightly as delivery workload increases.
